One line of out-of-office auto-reply, written to be funny enough that a
real person would actually set it — and surprising enough to beat a
thousand inboxes of the same old jokes.

## The entry

> Gone until the 14th. I've stopped checking email so completely that I forgot I set this reply. This message is a surprise to me too.

The twist: the sender is so thoroughly disconnected they forgot they
set the auto-reply at all — so the reply itself is as surprised as the
reader. No colleague covering, no pet on inbox duty, no holiday, no
"reply-all if urgent". Just a person who has genuinely, completely
checked out.

## Run it

```sh
python3 main.py   # writes the line to /output/entry.txt
```

Python 3.13 standard library only. Deterministic: every run writes the
same bytes.
